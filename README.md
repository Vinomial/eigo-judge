# eigo-judge(英語ジャッジ)

TOEIC 550点を目指す,競技プログラミング風の英語学習アプリ.スマホで手軽に解けます.

- 単語(3190語):語根・接辞から意味を「導出」して覚える.導けない語も,長文に出てくるものはすべて収録
- 文法(670問・67の定理):「定理」と前提の「定義」で解説する.1つの定理につき10問あり,定理ごとに続けて解ける
- 長文(106題.うち Part 6 の穴埋め16題,3つの文書を読み比べる問題4題):根拠の文と所要時間を示す.表・グラフつきの問題,2つの文書を見比べる問題もある
- 分からない問題は「わからない」を選べる(当てずっぽうの正解を防ぐ)
- 単語は「英語→意味」と「意味→英語」の両方向.取り違えやすい語(affect と effect など)も選択肢に出る
- 選択肢の並びは毎回変わる.すべての文法・長文の問題に,誤答の選択肢ごとの説明がある
- ショップ:解いてためたコインで,テーマ(19種)・フォント・タブのアイコン・正解の演出を買える
- 問題一覧:AtCoder Problems のように,難易度の色帯ごとに AC / WA を色分けして表示し,好きな問題を選んで解ける
- ミニ模試:TOEIC のリーディングと同じ配分の半分(50問・38分)
- 解き直し・復習・未挑戦:間違えた問題を総合・分野別に解き直す.文法も間隔反復で復習する
- いろいろな練習:今日の問題(毎日5題.全員同じ),早解き(単語60秒・文法3分),語根の問題(語根・接辞の意味),つづり入力(意味を見て打ち込む)
- みんなで難易度を推定:ログインした人どうしで最初の解答を持ち寄り,難易度を推定し直す
- 本番モード(総合・単語・文法・長文から選ぶ):AtCoder と同じ方式でパフォーマンスとレート(総合・分野別)を計算する
- 推定 TOEIC スコア:本番の出来から目安の点数を表示する.実際の点数を記録すると補正される
- 記録:成績・学習・実績・分析・データのタブに分けて表示.レートのグラフ,本番の履歴,日ごとの記録,草(日ごとの AC 数),難易度の推定,苦手な定理,実績(75個.進み具合つき)

## 使い方

公開版:https://vinomial.github.io/eigo-judge/

スマホではブラウザの「ホーム画面に追加」でアプリのように使えます.
進捗はブラウザごとに保存されます.「記録」画面の「端末間の同期」でログインすると,スマホと PC などで記録が自動でそろいます(ログインは任意).ログインしない場合は「書き出す」「読み込む」で移せます.

- iPhone では,ホーム画面に追加したアプリと Safari で開いたページは保存場所が別です.どちらか一方(おすすめはホーム画面のアイコン)に決めて使ってください.
- ブラウザが保存データを消すことがあるので,ときどき「書き出す」でバックアップを取ると安心です.

手元では `index.html` をブラウザで開くだけで動きます.

## 問題の追加

`npm run new -- grammar T12` などでひな形を出し,`data/` のファイルに追記して,`npm test` でエラーがないことを確かめます(初回は `npm install`).書き方は `CLAUDE.md` にあります.
公開するときは,更新履歴(`data/changelog.js`)に1件足してから `npm run release` を実行し,コミットして push します.

## 公開(GitHub Pages)

リポジトリの Settings → Pages で,Source を「Deploy from a branch」,Branch を `main` / `(root)` にします.
